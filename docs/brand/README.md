# Asterism brand assets

The mark is **Quadrant**: four tiles on a 64-unit grid (tiles 25, gutter 4).
Only the inner corners are rounded (radius 16), so the gutters open into a
four-point star: the star is the space between your services.

| File | Use |
|---|---|
| `mark.svg` | Colour mark (blue → teal → green); works on light and dark |
| `mark-white.svg`, `mark-black.svg` | One-colour marks |
| `logo-dark.svg` | Mark and wordmark for dark backgrounds |
| `logo-light.svg` | Mark and wordmark for light backgrounds |
| `og-image.svg` | Source of the 1200×630 link-preview image |

The web app's favicons, home-screen icons, `og-image.png` and
`site.webmanifest` live in `web/public/`. Everything here and there is
generated by `scripts/brand/generate.py`; edit the geometry or colours in that
script and rerun it rather than editing outputs by hand.

Gradient: `#8fb0ff` → `#4d7dff` → `#1fb6cf` → `#3fe0a4`. The wordmark is
Manrope Bold (SIL Open Font License 1.1), converted to outlines.
